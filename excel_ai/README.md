New here? Read the human quick start first: [`../QuickStart.docx`](../QuickStart.docx). AI agents: [`core/AGENTS.md`](core/AGENTS.md).

## The workbooks

Start with the **Master workbook, [`active_workbooks/CPAT-AI-Master_UserGuide.xlsm`](active_workbooks/)** (Excel 365, macros on): the user guide, the list of the modules (latest version, where they are), and every macro. It **activates** each module: opens its `.xlsx`, fills the formulas from 2035 to 2041, recalculates and saves `<Name>_latest.xlsb` next to itself. Work in the `.xlsb`. (v1.2.0, user 2026-10-31.)

| File | What it is |
|---|---|
| `active_workbooks/CPAT-AI-Master_UserGuide.xlsm` | **The Master**: user guide, module table, activation, data update, distribution update, stored scenarios and their comparison |
| `mitigation/CPAT-AI-Mitigation_latest.xlsx` | **The mitigation module** (no macros; activated: `active_workbooks/CPAT-AI-Mitigation_latest.xlsb`) |
| `distribution/CPAT-AI-Distribution_latest.xlsx` | **The distribution module**: household effects by decile of a mitigation scenario (the Master copies the mitigation exports into it) |
| `air_pollution/CPAT-AI-AirPollution_latest.xlsx` | The air-pollution scaffold (calculations and regression open) |

Every version, the current one included, is in the module's `releases/` folder (`<Name>_v<version>`; releases to 1.1.0 keep their old names, `CPAT-AI-Mitigation-Prototype_v1.1.0.xlsm`...). The `.xlsb` are generated by the Master: never merged, activated again.

## The documents

| File | What it is |
|---|---|
| [`bugs_and_legacy/`](bugs_and_legacy/)`Legacy_CPAT_Bugs_v<version>.docx` | **The legacy CPAT bugs**: the rule (bugs and issues; data problems are issues), every legacy bug found and fixed (prototype and legacy 465), the data problems by priority, each bug with its cell-level fix plan |
| [`bugs_and_legacy/`](bugs_and_legacy/)`Tracking_Legacy_Bugs_v<version>.xlsx` | **The master list of bugs and issues** (every module, the same columns): tabs ReadMe, Bugs, Issues, then the CPAT team's tabs |
| `CPAT-AI_CodesMap_v<version>.xlsx` (here) | **The codes map**: the code protocol, vocabularies, variables, output codes and every input |
| `CPAT-AI_Overview_v<version>.pptx` (here) | **The slide deck**: status, how to use it, results |

Older versions: `bugs_and_legacy/register/releases/` (bug book, tracker, codes map), `mitigation/releases/` (deck).
