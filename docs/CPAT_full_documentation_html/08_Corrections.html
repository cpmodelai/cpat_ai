8  Corrections

This edition of the methodology is the CPAT team’s 2023 text with errors corrected in place. The errors were found by the CPAT-AI project while it rebuilt CPAT in Excel and Python and wrote out every equation (the Documentation bugs DOC1-DOC20 of its register, excel_ai/core/BUGS.md). No model changes: CPAT, Excel-AI and CPAT Python already compute what the corrected text says.

NoteThe PDF download

The downloadable PDF is the 2023 edition, without these corrections. Read the web pages for the corrected text.
